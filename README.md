# Old_glasses — 个人作品集

参考 [A24 — Ravi Klaassens](https://a24.raviklaassens.com/) 与提供的视频，制作了以光盘为作品入口的响应式作品集。使用 Vite、TypeScript、Three.js 和 CSS，无需后端。原站画布标记为 Three.js r178，本项目采用相同版本的渲染引擎。

## 本地运行

在项目目录打开终端，执行：

```bash
# 首次运行时安装依赖
npm install

# 启动网站，打开终端输出的本地地址
npm run dev
```

```bash
# 检查类型并生成可部署的 dist 文件夹
npm run build

# 预览构建后的版本
npm run preview
```

## 已实现

- 首次打开以大号衬线滚动数字入场，经过 `0 → OG → 两段进度 → 100`；数字沿真实主盘从下方绕至左侧、顶部，CD 从侧面升起转正，完成后放大并展开邻盘。
- Loading 使用透明全屏层，桌面左右边缘显示品牌与滚动年份，手机隐藏边缘文字；标志、导航和作品资料依次出现，准备期间页面不可操作。
- 提前准备本地字体、可选封面图片与全部作品详情，再绘制印刷贴图、编译三维材质、上传正反面纹理并渲染第一帧，完成后衔接 CD 展开入场。
- 进度按六个准备阶段累计，演出进度受真实准备状态限制，场景就绪前最多推进至 18%；字体和封面超时后使用固定回退，不在入场后突然换字体或封面。三维模块加载失败或无 WebGL 时仍可进入 CSS 画廊。
- 真实三维光盘：实体厚度、镂空中心孔、独立印刷正面和银色虹彩背面，光照随角度变化。
- 侧边采用连续圆角旋转曲面与解析法线，避免反光分块；圆周为 256 段，桌面像素密度最高为 2、手机为 1.5，总渲染像素不超过 1200 万。
- 光盘按完整旋转范围分配前后深度，并补偿透视尺寸；左下方光盘完整遮住右上方后续光盘。
- 鼠标悬停时轻微倾斜、抬起，并绘制带笔锋、粗细变化和不同断口的双层手绘弧线；弧线参与真实三维遮挡，移开后逐帧收回。
- 印刷覆膜有独立法线与粗糙度，背面具备径向高光和局部色散；中心环由磨砂孔壁、金属压片环和透明外环组成，带真实厚度与微弧截面。
- 暗色环境中的四条柔光带配合暖色主灯、补光、蓝色轮廓灯与顶部条形灯，保留银环灰阶和覆膜反光。
- 在光盘上拖动可绕多个轴旋转，松手后用 1200ms 的缓出曲线自动回到默认陈列姿态；归位途中再次拖动从当前角度接续，无需额外的翻面或归位控件。
- 桌面全屏斜向陈列，主盘优先按视口高度定尺寸，近正方形窗口不再被较窄的宽度上限压小；手机、平板采用中央主盘与两侧缩小下沉的预览，导航移至底部；短横屏将资料与主盘分开放置。
- 使用 `cubic-bezier(.32,.72,0,1)` 控制切换，滚轮切换为 510ms，点击跨越更多作品时适当延长；新操作从眼前的位置接续。
- 触控板惯性尾巴合并为一次切换，重新发力或持续滚动可继续浏览，反向输入立即响应。
- 切换时按速度轻微倾斜、转向，各盘有受限的跟随差异；深度仍按统一进度分配，保留防穿模空间。
- 拖动时跟手，松手按最后的速度与方向停靠；选中状态在实际进度跨过中点时更新。旧描述向上逐行退出后才换文，新描述从下方错峰展开，细线右收左展；连续操作只显示最新作品，进入途中可反向收回。
- 鼠标拖动、触摸滑动、横向和竖向滚轮、方向键、Home / End 与切换按钮。
- 中央展开的作品索引、分类筛选；手机、平板导航固定于底部。
- 首页采用贴边的紧凑资料与居中双列描述；详情采用两行标题、贯穿式资料细线与四角标记的入口留白，下方保留设计展示和下一个作品。
- 详情交接后，标题、资料、细线、角标和按钮按独立节奏出现；下方说明随滚动逐行进入。按实际中文和英文换行生成临时遮罩，结束后恢复自然排版，窗口变化或导航取消时统一清理。
- 点击当前 CD 后轻压回弹、邻盘错峰退场、主盘旋转收起；670ms 时详情开始出现，原 3D 画布继续完成余下动画，1080ms 时归还舞台。返回时主盘从侧面展开，邻盘依次入场。
- 转场保持点击瞬间的旋转姿态，尚未完成的自动归位在返回画廊后继续；快速切页会取消旧时间轴并清理临时画布。减少动态、后台页面或 WebGL 不可用时直接切页。
- Hash 路由支持直接打开作品、刷新和浏览器前进/后退，返回后保留画廊状态。
- 关于介绍、复制个人 ID；Escape 关闭索引或返回画廊。
- 桌面与移动端布局，以及减少动态效果的系统偏好适配。

首页是全屏浏览模式，横向和竖向滚轮均切换作品。鼠标拖动光盘旋转，拖动空白区域浏览；触屏横滑切换作品，纵拖盘面旋转，即使从盘面起手也能横滑。旋转后松手或触摸被取消时自动回正，屏幕外的光盘也会完成归位；减少动态时直接回正。点击当前光盘打开详情，拖动不会触发打开。详情及关于页恢复正常页面滚动。首尾作品有边界，不会突然跳到另一端。改变窗口尺寸、打开索引或返回首页时，仍保留所选作品。

这是基于原站视觉与交互的个人化实现：首页和跨页转场由同一个 Three.js 画布实时渲染，详情页内的静态展示仍使用 CSS 光盘，未实现原站的 WebGL 视频溶解效果。WebGL 不可用或上下文丢失时，首页自动回退到 CSS 陈列。三维模块独立加载并在 Loading 期间预热，无交互时停止渲染；悬停描边以 10fps 更新，移动端限制像素密度。项目封面与内容使用个人作品集概念示例。

通过 [REA 6.7.0](https://github.com/morluto/rea) 的 CDP 网页检查读取原站公开页面和主脚本，并对比同尺寸的静止 / 悬停截图。确认原站存在双层手绘外轮廓、约 0.21 的悬停倾斜参数、独立法线 / 粗糙度贴图及透光中心环。本项目据此独立实现交互与材质；环线采用三维带状几何和深度测试，避免覆盖到前方光盘上。REA 仅用于本地分析，不是网站运行依赖。

2026-10-20 再次通过 REA 的 CDP 读取原站运行中的主脚本 `main.qdXy8l6N.js`，并实际操作滚轮、查看手机和平板布局。确认了 `.32,.72,0,1` 曲线、510ms 滚轮时长、560ms 甩动时长、150ms 手势间隔、速度倾斜以及 991px / 767px 断点。本项目采用这些运动规律，并为现有三维防穿模方案限制跟随偏移，为短横屏单独预留导航空间；不是原站完整源码的复制。

后续按同尺寸截图校正主盘尺寸，并对照原站公开脚本和实际详情导航补全 CD 转场。参考了 120ms 轻压、160ms 回弹、800ms 收起、670ms 页面交接的节奏，以及柔光环境和三段中心环。灯光方向适配本项目的三维坐标；路由采用可取消的独立时间轴，不依赖浏览器页面快照。

Loading 参考原站公开脚本、样式和实际加载中的元素位置重新实现：采用四段数字节拍、绕盘半椭圆轨迹、0.8 倍主盘与 1150ms 展开。原站的 A24 字样替换为 OG，字体使用本站 Bodoni Moda；没有进度条或独立装饰银盘。数字滚轮、投影轨迹和三维演出由同一帧调度，窗口变化会重新计算投影，改变地址、切后台、减少动态或 WebGL 丢失时统一归还画布并结束演出。

排版与文字演出继续对照原站实际 DOM 尺寸、样式与公开脚本：桌面以视口的 1/120 作为单位，详情标题约 5vw；描述退出 400ms、进入 700ms，详情标题逐行相隔 80ms，资料、细线和入口依次展开。文字控制器与 CD 渲染分开，路由取消由同一个 AbortSignal 驱动；屏幕阅读器的作品播报单独维护，不随拆行重复播报。

## 替换内容

`src/data.ts` 是唯一的作品数据入口：

- `PROFILE`：个人 ID、简介等。
- `PROJECTS`：作品标题、分类、时间、说明和封面。
- `FILTERS`：分类名称。

`src/gallery-config.ts` 是画廊的手感与响应式配置入口：

- `GALLERY_MOTION`：曲线、切换时长、滚轮手势阈值、甩动投射、速度倾斜与跟随上限。
- `GALLERY_LAYOUT`：断点、主盘尺寸、两侧预览比例、下沉距离与短屏留白。

`src/disc-config.ts` 中的 `DISC_3D` 管理光盘尺寸、旋转、悬停弹性与自动归位时间（`returnDuration`），`DISC_FINISH` 管理材质参数，`DISC_LIGHTING` 管理灯光与环境反射，`DISC_HUB` 管理中心环结构，`DISC_OUTLINE` 管理手绘弧线的宽度、间距、抖动与逐帧节奏。

`src/disc-transition.ts` 中的 `DISC_TRANSITION` 管理跨页动画的按压、回弹、收起、交接、返回和错峰时长；时间轴在取消、切后台或减少动态偏好变化时会统一收尾。

`src/content-motion-config.ts` 管理文字退出、进入、逐行间隔、换高、细线与角标的时间。`text-motion.ts` 负责真实换行测量和临时遮罩；`gallery-caption.ts` 只维护文案演出，不修改选中作品；`page-reveal.ts` 负责详情入场与滚动显示。排版单位和边距在 `style.css` 的 `--layout-unit`、`--page-edge` 中统一调整。

`src/loading-config.ts` 管理准备阶段权重、加载时限、品牌、数字节拍、绕盘间距和展开参数。`preload-assets.ts` 缓存已解码的封面，`page-cache.ts` 预生成详情，`loading-screen.ts` 负责入场调度，`loading-counter.ts` 负责数字卷轴，`disc-opening.ts` 提供临时三维姿态采样。刷新会重新准备；同一次访问中的站内导航不会重复 Loading。减少动态时仍准备资源，但省略旋转入场。

首版的五个项目是明确标注的概念示例，不代表真实商业项目；三维封面由 `src/disc-textures.ts` 绘制，详情和回退封面由 `src/artwork.css` 绘制。没有使用参考视频中的电影海报，也没有虚构客户、工作成绩或联系方式。

准备好自己的封面后，将素材放进 `public/art/`，再给对应项目添加 `image`：

```ts
{
  // 保留作品的 id，避免链接关系发生变化。
  id: 'in-motion',
  image: '/art/my-project.webp', // 自己的封面，优先使用正方形 WebP。
  // 其他字段按原数据填写。
}
```

`image` 存在时优先使用图片，否则显示原创程序封面。填写真实作品时，同时修改详情页的概念示例标注。联系区目前只复制已提供的个人 ID；如需邮件联系，应填入真实邮箱再改为邮件入口。

## 代码结构

```text
src/
  data.ts       # 统一的个人信息与作品数据
  disc.ts       # 可复用的光盘结构
  disc-config.ts # 几何、悬停手感与材质的集中参数
  disc-layout.ts # 响应式构图、安全深度与共用屏幕坐标
  disc-model.ts # 带孔实体模型与正反面组合
  disc-geometry.ts # 平滑圆角侧壁与连续法线
  disc-materials.ts # 摄影棚环境、金属反射与局部衍射
  disc-highlight.ts # 参与深度遮挡的三维手绘笔触
  disc-transition.ts # 可取消的 CD 跨页时间轴、缩放和旋转采样
  disc-opening.ts # 首次入场的姿态、缩放与真实投影接口
  disc-textures.ts # 原创印刷封面与背面沟槽贴图
  disc-scene.ts # 三维场景、真实命中检测、旋转与自动归位
  gallery.ts    # 画廊状态与鼠标、触摸、键盘交互
  gallery-config.ts # 切换手感、滚轮阈值与响应式参数
  gallery-motion.ts # 单一动画进度、曲线、惯性手势与停靠
  gallery-caption.ts # 描述退出、换文、进入与快速反向衔接
  content-motion-config.ts # 文字、细线、角标与换高的统一时间表
  text-motion.ts # 按实际换行生成遮罩、保留字形并恢复原节点
  page-reveal.ts # 页面分层入场、滚动显示与路由取消清理
  loading-config.ts # 启动阶段、字体路径与超时配置
  loading-screen.ts # 准备进度、绕盘轨迹与统一入场时间轴
  loading-counter.ts # 带遮罩的数字卷轴、品牌切换与错峰退出
  preload-assets.ts # 字体和封面预加载、解码与共享缓存
  page-cache.ts # 提前生成作品详情与关于页
  main.ts       # 页面路由、索引菜单和辅助交互
  pages.ts      # 作品详情、关于页面及共用图标
  style.css     # 页面布局、材质、动画与响应式
  artwork.css   # 五张原创程序封面
```

字体使用随网站提供的 Bodoni Moda 和 DM Sans 拉丁字符 WOFF2（共约 64KB），来源于 Google Fonts，许可文件位于 `public/fonts/`。中文使用系统字体；本地字体加载失败时保持本机字体回退。运行时不再请求 Google Fonts。网站没有数据上传、第三方统计或后端服务。
