# Old_glasses — 个人作品集

参考 [A24 — Ravi Klaassens](https://a24.raviklaassens.com/) 与提供的视频，制作了以光盘为作品入口的响应式作品集。使用 Vite、TypeScript、Three.js 和 CSS，无需后端。原站画布标记为 Three.js r178，本项目采用相同版本的渲染引擎。

## 本地运行

在项目目录打开终端，执行：

```bash
# 首次运行时安装依赖
npm install

# 启动网站，打开终端输出的本地地址
npm run dev
```

```bash
# 检查类型并生成可部署的 dist 文件夹
npm run build

# 预览构建后的版本
npm run preview
```

## 已实现

- 真实三维光盘：实体厚度、镂空中心孔、独立印刷正面和银色虹彩背面，光照随角度变化。
- 在光盘上拖动可绕多个轴旋转，松手后有衰减惯性；翻面 / 归位按钮与 F / R 快捷键。
- 全屏斜向陈列，左上角作品资料、中央小导航与底部设计理念。
- 连续滚轮与空白区域拖动浏览、松手停靠、光盘与资料联动。
- 鼠标拖动、触摸滑动、横向和竖向滚轮、方向键、Home / End 与切换按钮。
- 中央展开的作品索引、分类筛选；手机导航固定于底部。
- 完整作品详情、贯穿式资料分隔线、设计展示与下一个作品。
- 支持 View Transition 的浏览器有页面切换动画，其他浏览器正常切页。
- Hash 路由支持直接打开作品、刷新和浏览器前进/后退，返回后保留画廊状态。
- 关于介绍、复制个人 ID；Escape 关闭索引或返回画廊。
- 桌面与移动端布局，以及减少动态效果的系统偏好适配。

首页是全屏浏览模式，横向和竖向滚动均切换作品；拖动光盘旋转，拖动空白区域浏览。点击当前光盘打开详情，拖动不会触发打开。详情及关于页恢复正常页面滚动。首尾作品有边界，不会突然跳到另一端。

这是基于原站视觉与交互的个人化实现：首页光盘由 Three.js 实时渲染，详情页仍使用 CSS 光盘，未实现原站的 WebGL 视频溶解效果。WebGL 不可用或上下文丢失时，首页自动回退到 CSS 陈列。三维模块按需加载，静止时停止渲染，移动端限制像素密度。项目封面与内容使用个人作品集概念示例。

## 替换内容

`src/data.ts` 是唯一的作品数据入口：

- `PROFILE`：个人 ID、简介等。
- `PROJECTS`：作品标题、分类、时间、说明和封面。
- `FILTERS`：分类名称。
- `MOTION`：滚轮步幅、停靠延时、跟随速度、光盘尺寸与斜向间距。

`src/disc-model.ts` 中的 `DISC_3D` 管理光盘尺寸比例、旋转灵敏度、惯性和翻面时间。

首版的五个项目是明确标注的概念示例，不代表真实商业项目；三维封面由 `src/disc-textures.ts` 绘制，详情和回退封面由 `src/artwork.css` 绘制。没有使用参考视频中的电影海报，也没有虚构客户、工作成绩或联系方式。

准备好自己的封面后，将素材放进 `public/art/`，再给对应项目添加 `image`：

```ts
{
  // 保留作品的 id，避免链接关系发生变化。
  id: 'in-motion',
  image: '/art/my-project.webp', // 自己的封面，优先使用正方形 WebP。
  // 其他字段按原数据填写。
}
```

`image` 存在时优先使用图片，否则显示原创程序封面。填写真实作品时，同时修改详情页的概念示例标注。联系区目前只复制已提供的个人 ID；如需邮件联系，应填入真实邮箱再改为邮件入口。

## 代码结构

```text
src/
  data.ts       # 统一的个人信息、作品和交互配置
  disc.ts       # 可复用的光盘结构
  disc-model.ts # 带孔实体模型、正反面材质与三维参数
  disc-textures.ts # 原创印刷封面与背面沟槽贴图
  disc-scene.ts # 三维场景、真实命中检测、旋转与惯性
  gallery.ts    # 画廊状态与鼠标、触摸、键盘交互
  main.ts       # 页面路由、索引菜单和辅助交互
  pages.ts      # 作品详情、关于页面及共用图标
  style.css     # 页面布局、材质、动画与响应式
  artwork.css   # 五张原创程序封面
```

字体通过 Google Fonts 加载 Bodoni Moda 和 DM Sans；网络受限时使用本机字体回退。网站没有数据上传、第三方统计或后端服务。
